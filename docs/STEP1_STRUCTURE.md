# Step 1 — Project structure

## Plan

1. Feature-first folders for every product module
2. Core: theme (Tom-like palette), router skeleton, constants
3. pubspec with Riverpod / go_router / Hive / Rive / freezed
4. Entry `main.dart` + `app.dart`
5. Verify `flutter analyze` on structure

## Out of scope (later steps)

- Rive character animation (Step 2)
- Full room gameplay (Step 4+)
- Growth formulas implementation polish (Step 5)
- Minigames / chat LLM / friends (Steps 6–9)

## Done when

- [x] All feature modules exist with data/domain/presentation/providers/widgets
- [x] Theme + router cover all product routes
- [x] Docs describe architecture and build order
- [x] App compiles
