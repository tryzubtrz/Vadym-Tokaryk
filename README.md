# Turbulence Inc.

Оригінальна мобільна гра в жанрі хаотичного авіа-co-op для телефону (PWA).

> Це **не** копія *Dear Passengers*. Назва, арт, текст і механіка — окремий проєкт. Жанрове натхнення — пілот + салон + ризикований вантаж.

## Що всередині

- Передпольотний вибір пасажирів і вантажу (ризик / виплата)
- Політ з двома ролями: **Пілот** і **Салон**
- Турбулентність, сервіс пасажирів, незакріплений вантаж, оцінка рейсу
- Mobile-first UI + встановлення на домашній екран (PWA)

## Запуск

```bash
npm install
npm run dev
```

Відкрий URL з телефону в тій же мережі або через тунель. Для «як додаток» — *Add to Home Screen*.

```bash
npm run build
npm run preview
```

## Керування

- **Пілот** — тягни стік у нижній частині екрана, тримай горизонт
- **Салон** — тапай `!` біля пасажирів і червоний незакріплений вантаж
- Перемикай ролі кнопками під грою

## Стек

Vite · TypeScript · Canvas 2D · vite-plugin-pwa
