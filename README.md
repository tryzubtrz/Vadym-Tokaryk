# Turbulence Inc.

Оригінальна **3D** мобільна гра в жанрі хаотичного авіа-co-op (PWA).

> Не копія *Dear Passengers*. Окремий проєкт: назва, код, арт і текст свої. Жанрове натхнення — пілот + салон + ризикований вантаж.

## Геймплей

- 3D салон літака (Three.js) + фізика (cannon-es)
- Ролі **Пілот** / **Салон**
- Пасажири з запитами сервісу, вантаж що зривається, турбулентність
- Touch: стік, огляд, кнопка «Дія»

## Запуск

```bash
npm install
npm run dev
```

Телефон у тій же Wi‑Fi: `npm run dev -- --host`

```bash
npm run build
npm run preview
```
