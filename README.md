# AstraForge AI

Автономный ИИ-торговый агент для крипто perpetual futures.

Полный проект находится в каталоге [`astraforge/`](./astraforge/).

```bash
cd astraforge
cp .env.example .env
# заполните ключи Telegram / биржи / LLM
docker compose up --build -d
```

См. подробности и предупреждения о рисках в [`astraforge/README.md`](./astraforge/README.md).
